# DeepTutor Desktop 1.6.5

基于官方 DeepTutor **v1.6.5** 的 macOS 桌面封装（Electron 瘦包，官方源码零改动）。

## 本版变化

- 同步官方上游 **v1.6.4 → v1.6.5**（24 个提交，529 个文件变更，+46470 / -12112 行）。
- 桌面层版本号跟随官方，由 `1.6.4` 升到 `1.6.5`。
- 桌面层代码本身无改动，仅版本号与发布说明更新。

### 官方 v1.6.5 主要更新

本次更新聚焦于「子代理后端加固、LightRAG 索引可控、视频学习增强、会话与搜索稳健性」。

**新功能**

- **加固版远程 Hermes 子代理后端（#1213）**：先在 #1208 引入、随后在 #1212 回退的远程 Hermes 连接子代理后端，于 #1213 以加固形态回归，更稳健可靠。
- **LightRAG 索引模型可控（#1171 / #1174）**：可按知识库锁定 LightRAG 索引模型，并新增索引模型控制与溯源信息（provenance）。
- **视频学习增强**：连接 Invidious 账号（#1192/#1193）+ 拆分 Invidious 账号适配器（#1211）；新增可视化学习看板（#1194）；保持活动转写字幕可见（#1164/#1165）；支持将带时间戳的笔记导出为 Markdown（#1203/#1204）。
- **搜索安全（#1205）**：过滤不安全的网络搜索标题与摘要。

**修复与优化**

- **会话性能（#1191）**：惰性加载回合事件 trace，启动与切换更轻量。
- **中文 Markdown 流式（#1178）**：流式输出时保留原始内容，避免中文渲染异常。
- **Web 修复**：设置面板滚动限制在自身区域（#1160）；遗留 mastery /study 链接重定向到 /sessions（#1196）；测验卡片文本正确解码 Unicode 转义（#1162）；视频学习恢复时延迟加载已存材料（#1169）。
- **LLM（#1195）**：DeepSeek 推理回放 400 错误时自动回退到 Responses 回合。
- **应用更新检测（#1186）**：更准确识别源码检出，判断应用更新更可靠。
- **CI（#1210 / #1201）**：稳定依赖与阅读门禁、恢复 dev 发布检查。
- **cron 测试（#1197）**：覆盖跨平台迁移锁。

## ✨ 桌面层功能（承袭自 1.5.15 / 1.5.16 / 1.5.17 / 1.6.0 / 1.6.4）

- **启动动画**：启动时 logo 呼吸动画，主页就绪后自动切换，告别启动白屏空窗。
- **无标题栏窗口**：隐藏 macOS 原生标题栏，改为 28px 自定义标题栏空间——左上角红绿灯按钮、顶部按住可拖动、双击可缩放。
- **主题跟随标题栏**：标题栏空间颜色实时跟随官方主题（浅色 / 深色 / 琉璃 / 奶油），并随左侧边栏收缩/展开联动。
- **托盘状态图标**：服务运行中托盘图标变为绿色（#34C759），停止/异常时恢复黑色模板图标（自动适配菜单栏明暗）。
- **进程隔离**：子进程调用官方 `deeptutor start`，不 import 官方 Python 代码；官方内部实现变化对桌面层无感知。
- **PATH 兜底**：GUI 启动时自动补 `/opt/homebrew/bin`、`/usr/local/bin` 与用户级 TeX Live（Manim 公式渲染依赖）。

## 📦 安装说明

1. 解压 zip，将 `DeepTutor.app` 拖入「应用程序」。
2. macOS 15 对未签名应用有安全提示：**首次运行请右键 DeepTutor.app → 打开**，在弹窗中点击「打开」。
3. 应用数据目录：`~/Library/Application Support/DeepTutor`。

> 需要完整安装的额外依赖（可选）：dev / partners / matrix / matrix-e2e / math-animator，对应官方 `pip install -e ".[...]"`。
