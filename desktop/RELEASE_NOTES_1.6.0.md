# DeepTutor Desktop 1.6.0

基于官方 DeepTutor **v1.6.0** 的 macOS 桌面封装（Electron 瘦包，官方源码零改动）。

## 本版变化

- 同步官方上游 **v1.5.17 → v1.6.0**（224 个文件变更，+19036 / -948 行）。
- 桌面层版本号跟随官方，由 `1.5.17` 升到 `1.6.0`（沿用 `desktop-v1.6.0` tag 命名）。
- 桌面层代码本身无改动，仅版本号与发布说明更新。
- 前端依赖新增 `@recogito/text-annotator`、`epubjs`（官方阅读器标注与 EPUB 渲染所需），已随本次构建一并安装。

### 官方 v1.6.0 主要更新

本版主题为「互联学习工作区」——阅读器、课程、知识来源三条线打通。

**新功能**

- **课程工作区与划词辅导（#996）**：新增课程组织能力，选中文本即可发起针对性讲解，回答严格基于所选原文。
- **知识库网页来源同步（#904）**：网页来源改为可同步的知识项，同步过程带边界限制，详情视图可查看已同步来源。
- **上下文感知追问卡（#776）**：回答后可生成确定性追问建议，追问答案会回填进后续对话上下文。
- **EPUB 阅读器全面升级**：忠实还原排版（#968、#969）、持久化 W3C 文本选择器与高亮（#972、#974）、显式双语配对（#979）、可调节文本显示偏好（#985）、持久化文档大纲（#991）、长章节顺序翻页（#998）。
- **阅读器安全扩展协议（#970）**：扩展动作有界执行，超时与畸形目录被隔离，不再拖垮主流程。
- **原生服务端搜索（#1003）**：`web_search` 映射到 Responses 原生工具，由服务端执行搜索。
- **Serply 搜索 provider（#1006）**：新增 Serply，支持网页 / 新闻 / 学术三种模式。
- **llama.cpp 上下文窗口自动读取（#1005）**：从模型元数据提取上下文长度，无需手工填写。

**修复与加固**

- **引导式学习（mastery）**：纯文本测验强制走卡片（#1002）；输入框里的澄清文字不再卡住选项闸门（#1007）；Unicode 转义与不可见控制字符正确解码显示（#975）。
- **LLM 适配**：Kimi k3 裸模型 ID 在编码端点去掉 temperature（#977）；schema 回退检测器不再误匹配裸 `tool`（#1008）；provider spec 的 `model_overrides` 在 agentic 链路生效。
- **RAG**：修复非对称 embedding 上下文丢失（#989）。
- **会话**：对话压缩预算有界化，长对话不再无限膨胀（#772）。
- **Codex**：TLS 校验失败时快速失败而非继续（#988）。
- **Windows 兼容性（#986）**：runner、工具与测试的跨平台问题集中修复。
- **CI（#981）**：release tag 增加校验分类与 latest 保护。

## ✨ 桌面层功能（承袭自 1.5.15 / 1.5.16 / 1.5.17）

- **启动动画**：启动时 logo 呼吸动画，主页就绪后自动切换，告别启动白屏空窗。
- **无标题栏窗口**：隐藏 macOS 原生标题栏，改为 28px 自定义标题栏空间——左上角红绿灯按钮、顶部按住可拖动、双击可缩放。
- **主题跟随标题栏**：标题栏空间颜色实时跟随官方主题（浅色 / 深色 / 琉璃 / 奶油），并随左侧边栏收缩/展开联动。
- **托盘状态图标**：服务运行中托盘图标变为绿色（#34C759），停止/异常时恢复黑色模板图标（自动适配菜单栏明暗）。
- **进程隔离**：子进程调用官方 `deeptutor start`，不 import 官方 Python 代码；官方内部实现变化对桌面层无感知。
- **PATH 兜底**：GUI 启动时自动补 `/opt/homebrew/bin`、`/usr/local/bin` 与用户级 TeX Live（Manim 公式渲染依赖）。

## 📦 安装说明

1. 解压 zip，将 `DeepTutor.app` 拖入「应用程序」。
2. macOS 15 对未签名应用有安全提示：**首次运行请右键 DeepTutor.app → 打开**，在弹窗中点击「打开」。
3. 应用数据目录：`~/Library/Application Support/DeepTutor`。

> 需要完整安装的额外依赖（可选）：dev / partners / matrix / matrix-e2e / math-animator，对应官方 `pip install -e ".[...]"`。
