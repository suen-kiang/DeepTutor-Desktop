# DeepTutor Desktop 1.6.6

基于官方 DeepTutor **v1.6.6** 的 macOS 桌面封装（Electron 瘦包，官方源码零改动）。

## 本版变化

- 同步官方上游 **v1.6.5 → v1.6.6**（40 个提交，127 个文件变更，+4541 / -372 行）。
- 桌面层版本号跟随官方，由 `1.6.5` 升到 `1.6.6`。
- 桌面层代码本身无改动，仅版本号与发布说明更新。

### 官方 v1.6.6 主要更新

本次更新聚焦于「Codex 登录打通、伙伴对话修复、阅读与知识库稳健性」。

**修复与优化**

- **Codex 登录（Docker 场景）**：粘贴回调地址即可完成 Docker 环境下的 Codex 登录；同步更新模型目录兼容版本。
- **伙伴（Partners）系列修复**：来源标识——显示伙伴对话来自哪个聊天（abd7fbcd）；文件下载——伙伴给出的文件可由提问者正常下载（4afc7ecc）；拒绝接管回合的知识库类型并完成连接配置（3466cf0c）；修复注册连接知识库时复制不存在目录的问题（31c8b104）。
- **共享代理循环**：将一轮的推理内容（reasoning）在共享 agentic 循环中传递下去（5f7e1651）。
- **多语言**：用户可直接要求换一种语言回答，且双语提示不再漂移（71e042fe）。
- **阅读**：修复批注弹层误触导致工具栏失效的问题（3466cf0c）。
- **知识库**：在管理器侧校验知识库名称、允许删除非法名称的知识库（e7d04fcc）；修复空知识库创建后的进度报错（eabdfa86）。
- **聊天**：保留待处理的 ask_user 回合（6c6ef741）；防止 PDF 附件引发工具幻觉（6cfbbe93）；被拒绝的回答可重新发送而非丢弃（#1273）。
- **Web 修复**：复制按钮不再虚报成功（895d2cce）；上传前移除客户端 Expect 头（2f546a55）；安全地规范化异常的 ATX 标题（85485a0f）。
- **LLM**：对不支持的 status 字段自动重试 Responses 请求（35d30638）；Kimi k3 系列统一命名（26500eeb）；支持 Moonshot k3-256k 温度覆盖（73b6db8e）。
- **笔记本**：持久化回答中的图片（44ae34f6）。
- **课程**：恢复课程访问（#1228）。
- **LightRAG**：原生 SDK 升级到 1.5.7 正式版（de483d65，可选 extra）。

## ✨ 桌面层功能（承袭自 1.5.15 / 1.5.16 / 1.5.17 / 1.6.0 / 1.6.4 / 1.6.5）

- **启动动画**：启动时 logo 呼吸动画，主页就绪后自动切换，告别启动白屏空窗。
- **无标题栏窗口**：隐藏 macOS 原生标题栏，改为 28px 自定义标题栏空间——左上角红绿灯按钮、顶部按住可拖动、双击可缩放。
- **主题跟随标题栏**：标题栏空间颜色实时跟随官方主题（浅色 / 深色 / 琉璃 / 奶油），并随左侧边栏收缩/展开联动。
- **托盘状态图标**：服务运行中托盘图标变为绿色（#34C759），停止/异常时恢复黑色模板图标（自动适配菜单栏明暗）。
- **进程隔离**：子进程调用官方 `deeptutor start`，不 import 官方 Python 代码；官方内部实现变化对桌面层无感知。
- **PATH 兜底**：GUI 启动时自动补 `/opt/homebrew/bin`、`/usr/local/bin` 与用户级 TeX Live（Manim 公式渲染依赖）。

## 📦 安装说明

1. 解压 zip，将 `DeepTutor.app` 拖入「应用程序」。
2. macOS 15 对未签名应用有安全提示：**首次运行请右键 DeepTutor.app → 打开**，在弹窗中点击「打开」。
3. 应用数据目录：`~/Library/Application Support/DeepTutor`。

> 需要完整安装的额外依赖（可选）：dev / partners / matrix / matrix-e2e / math-animator，对应官方 `pip install -e ".[...]"`。
