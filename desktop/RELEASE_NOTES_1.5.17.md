# DeepTutor Desktop 1.5.17

基于官方 DeepTutor **v1.5.17** 的 macOS 桌面封装（Electron 瘦包，官方源码零改动）。

## 本版变化

- 同步官方上游 **v1.5.16 → v1.5.17**（214 个文件变更，+14120 / -895 行）。
- 桌面层版本号跟随官方，由 `1.5.16` 升到 `1.5.17`（沿用 `desktop-v1.5.17` tag 命名）。
- 桌面层代码本身无改动，仅版本号与发布说明更新。

### 官方 v1.5.17 主要更新

**新功能**

- **Partners 扫码接入（#952）**：新增二维码渠道上线引导，微信侧支持扫码登录。
- **单会话推理强度覆盖（#958）**：可按会话单独设置 reasoning effort，不影响全局配置。
- **知识同步拆分 + GitHub 源同步（#903）**：知识库同步能力拆分，新增 GitHub 仓库作为知识来源。
- **`deeptutor setup doctor` 命令（#959）**：一键体检本地安装与依赖配置。

**修复与加固**

- **Embedding 抗限流（#962）**：密钥轮换、重试预算、全局节流，provider 触发 429 时不再整链失败。
- **RAG 管线**：LightRAG 本地溯源信息可见（#754）；MinerU 页面版式块在索引前过滤（#949）；LlamaIndex 本地管线兼容性改进（#864）；索引卡死时有界失败而非无限等待（#953）。
- **代码沙箱与解析（Windows）**：支持 Windows 下代码执行（#964）；修复 MinerU 解析的子进程 UTF-8 解码与渲染线程崩溃（#844）。
- **前端**：聊天流固定到延迟挂载的测验卡片，修复自动滚动错位（#960）。
- **语音**：STT 上传前剥离 MediaRecorder 的 codec 参数（#948）。
- **测验**：拒绝重复的 mastery quiz 选项（#956）。
- **CLI 依赖声明（#954）**：补齐独立安装缺失的运行时依赖（`pyte`、`loguru`、`json-repair`）。

## ✨ 桌面层功能（承袭自 1.5.15/1.5.16）

- **启动动画**：启动时 logo 呼吸动画，主页就绪后自动切换，告别启动白屏空窗。
- **无标题栏窗口**：隐藏 macOS 原生标题栏，改为 28px 自定义标题栏空间——左上角红绿灯按钮、顶部按住可拖动、双击可缩放。
- **主题跟随标题栏**：标题栏空间颜色实时跟随官方主题（浅色 / 深色 / 琉璃 / 奶油），并随左侧边栏收缩/展开联动。
- **托盘状态图标**：服务运行中托盘图标变为绿色（#34C759），停止/异常时恢复黑色模板图标（自动适配菜单栏明暗）。
- **进程隔离**：子进程调用官方 `deeptutor start`，不 import 官方 Python 代码；官方内部实现变化对桌面层无感知。
- **PATH 兜底**：GUI 启动时自动补 `/opt/homebrew/bin`、`/usr/local/bin` 与用户级 TeX Live（Manim 公式渲染依赖）。

## 📦 安装说明

1. 解压 zip，将 `DeepTutor.app` 拖入「应用程序」。
2. macOS 15 对未签名应用有安全提示：**首次运行请右键 DeepTutor.app → 打开**，在弹窗中点击「打开」。
3. 应用数据目录：`~/Library/Application Support/DeepTutor`。

> 需要完整安装的额外依赖（可选）：dev / partners / matrix / matrix-e2e / math-animator，对应官方 `pip install -e ".[...]"`。
